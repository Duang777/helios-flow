# @helios/ui 🎨

Composable UI toolkit for Helios backoffice and business apps.

`@helios/ui` includes backend UI patterns (CrudForm, DataTable, dialogs, detail sections, injections, notifications) and reusable primitives.

## Why this package ✨

- 🧭 Consistent backoffice UX patterns out of the box
- 🧩 Rich primitives + higher-level business components
- ⚙️ Works with Helios injection architecture
- 🚀 Speeds up delivery without sacrificing flexibility

## Install

```bash
yarn add @helios/ui
```
