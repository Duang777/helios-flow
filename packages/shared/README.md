# @helios/shared 🔧

The shared foundation for Helios packages.

`@helios/shared` provides cross-cutting utilities, contracts, DSL helpers, module registries, i18n helpers, and typed platform primitives.

## Why this package ✨

- 🧱 Shared types and contracts used across the ecosystem
- 🌍 I18n and translation helpers for server and client
- 🧠 Data/query abstractions and platform-level utilities
- 🧩 Stable building blocks for custom modules and extensions

## Install

```bash
yarn add @helios/shared
```
