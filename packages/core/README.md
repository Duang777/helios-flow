# @helios/core 🧠

Build production-grade business modules on top of the Helios platform.

`@helios/core` is the business engine: catalog, customers, sales, auth, workflows, settings, and module infrastructure.

## Why this package ✨

- 🧩 Ready-made domain modules for real business apps
- 🔐 Built-in ACL, tenancy, and secure-by-default conventions
- ⚡ Command-based architecture for robust writes and undo support
- 🛠 Extensible module system with API/page auto-discovery

## Install

```bash
yarn add @helios/core
```
