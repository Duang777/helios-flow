# @helios/events 📡

Event-driven backbone for Helios modules.

`@helios/events` enables typed event publication/subscription with support for ephemeral and persistent delivery patterns.

## Why this package ✨

- 🧩 Decouple modules with clean event contracts
- 🔁 Persistent subscribers for reliable side effects
- ⚡ Ephemeral events for real-time UX flows
- 🧠 Works with queue workers for scalable processing

## Install

```bash
yarn add @helios/events
```
