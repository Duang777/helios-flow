# @helios/content 📄

Static content module for policy and legal pages in Helios apps.

`@helios/content` provides a clean way to ship pages like Privacy Policy, Terms, and other managed static content.

## Why this package ✨

- 🧾 Legal and policy pages out of the box
- 🧩 Fits directly into the module auto-discovery system
- 🌍 Works with platform i18n workflows
- ⚡ Keeps static content maintainable and versionable

## Install

```bash
yarn add @helios/content
```
