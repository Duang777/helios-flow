# @helios/onboarding 🚀

Tenant onboarding and first-run experience for Helios.

`@helios/onboarding` helps orchestrate setup flows, initial configuration, defaults, and guided adoption steps.

## Why this package ✨

- 🪄 Guided tenant bootstrap experience
- 🧩 Hooks for setup defaults and example data
- 📬 Supports welcome and invitation-style flows
- ⚡ Reduces time-to-value for new installations

## Install

```bash
yarn add @helios/onboarding
```
