# @helios/scheduler ⏰

Database-backed scheduling for recurring and delayed jobs in Helios.

`@helios/scheduler` manages scheduled tasks with robust runtime control, queue integration, and visibility for ops teams.

## Why this package ✨

- 📅 Cron and delayed job orchestration
- 🧩 Native integration with Helios queue/events
- 🔎 Operational visibility and safer automation flows
- ⚡ Reliable scheduling for business-critical tasks

## Install

```bash
yarn add @helios/scheduler
```
