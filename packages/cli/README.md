# @helios/cli 🛠️

The command-line toolbox for Helios developers.

`@helios/cli` powers module generators, DB tasks, worker/scheduler runtime commands, and developer workflows.

## Why this package ✨

- ⚡ Fast project and module automation
- 🧬 Generators for registry/entities/DI/OpenAPI
- 🗃 Database lifecycle commands (generate/migrate/greenfield)
- 🔄 Queue worker and runtime orchestration utilities

## Install

```bash
yarn add @helios/cli
```
